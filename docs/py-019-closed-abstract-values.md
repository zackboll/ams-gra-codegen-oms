# PY-019 — Checked closed-world Python abstract values

## Scope and model API

Python consumes the existing shared `TypeEmission::AbstractValue` and
`AbstractValueProjection::concrete_descendants`; it does not compute a separate
descendant universe. The shared planner orders representation dependencies and
rejects recursive value graphs. Concrete Record fields come from
`effective_record_fields`, preserving inherited members and effective constraints.

An inhabited `ClosedSchemaSet` abstract target becomes a frozen, slotted wrapper:

```python
selected = model.ManagedListBaseType.from_ForeignKeyMapML(
    model.ForeignKeyMapML()
)
assert selected.alternative == (
    "https://www.vdl.afrl.af.mil/programs/oam", "ForeignKeyMapML"
)
```

The `alternative` is the original `(namespace, local_name)` QName, not a Python
identifier or shape inference. `value` has the exact generated concrete class.
Factories use `from_` plus the existing Python type-name policy. All concrete
transitive descendants occur in shared schema order, including concrete non-leaf
types; abstract intermediate declarations are not payload alternatives. Naming,
factory and wire-identity collisions fail before output. Exact-class checks and
recursive member validation remain active under `python -O`, including corrupted
frozen storage. The wrapper works in required, optional, repeated and compatible
Choice value positions. The original `__schema_name__` identities are retained.

`OpenExtensions` still fails at the shared
`NotClosedUnderOpenExtensions` projection boundary for zero, one or multiple
known descendants, including private overlays. No `Unknown`, opaque payload,
trust policy or shared IR change is introduced. Python continues to reject its
unsupported zero-descendant/absent-only representations. Ancestry-only abstract
Records remain un-emitted.

## OMS JSON codec

The existing public `encode_<Payload>(value) -> str` and
`decode_<Payload>(text) -> Payload` API is unchanged. At abstract positions the
codec uses the actual known concrete QName as `$type`, via the shared OMS QName
mapping, then invokes the ordinary checked concrete codec for inherited/local
members. It requires an exact known string discriminator and rejects malformed,
missing, abstract, unknown, mismatched and duplicate selectors without fallback.
Duplicate JSON keys are retained until their nested/indexed path can be reported.

Concrete-position behavior is intentionally preserved: the PY-004 concrete codec
rejects **all** `$type` members, even a schema-valid redundant self-type selector.
This is a documented bounded Python representation, not a general XSD codec.
Closed abstract-value support does not authorize arbitrary concrete-position
polymorphism. Codecs and models without abstract-value demands retain their
established generated bytes.

Pinned Sleet is `e38f61d8ce0d75c8508434a52f2ed77c69cf6a3b`, tree

R2's six invalid subtype/content probes were broker-rejected. Its duplicate
`$type` probe passed the broker but was rejected by the runtime envelope parser.
None reached the generated decoder. The mandatory attribution assertion was
correct to fail; those observations were not relabelled.

R3 independently proved a distinct, schema-valid **unsupported representation**:

```json
{"Required":{"Inherited":1,"Text":"z","$type":"Zeta"},"Bounded":[{"Inherited":3,"Real":1.5,"$type":"Alpha"}],"Nested":{"Text":"n"},"Concrete":{"Inherited":4,"Text":"c","$type":"Zeta"}}
```

Sleet accepts `Concrete.$type = Zeta` because it names the exact declared
concrete type. The unchanged generated Python codec rejects it at `$.Concrete`,
consistent with PY-004. This is **not** a malformed abstract payload and is
explicitly classified separately. The fixture has no concrete-to-concrete
derivation that could supply another candidate without changing its schema.

The permanent test requires actual broker `+OK`, byte-identical independent raw
OWP observation, exactly one generated-decoder invocation with the original
body, `CodecError` path/category, SID-bound `CodecFailure`, no typed callback,
and recovery on the same subscription. It retains all seven original malformed
controls and all six typed deliveries. Unsubscribe, callback silence, empty
subscriptions/tasks, connection close and broker termination are required.
No broker modification, mock delivery or validator bypass is used.
