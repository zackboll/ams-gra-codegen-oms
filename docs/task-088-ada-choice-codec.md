## Representation and wire semantics

The generated model and service API are unchanged. The model-only construction
consumer was compiled/executed before codec implementation with GNAT 14.2.0 and
16.1.0, with completion marker `TASK088_MODEL_COMPLETE cases= 7`.
The fixture's `Selection` is the existing discriminated Record with
`Selection_Kind`, `Kind`, and one component per alternative. Source `begin`
becomes `Alternative_begin` and `Alternative_begin_Kind`, not a wire-name change.

Encoding dispatches on `Item.Kind`, using fully qualified model literals, and
sets exactly one object field. Decoding first requires an object and counts its
normalized members, requires exactly one, selects its qualified wire key, and
returns a discriminated aggregate with the explicit `Kind` and active value.
There is no default-selection path, `Kind` wire member, `$type`, or discriminant
`'Image` key derivation. Provider duplicate-key policy remains last-value-wins;
this is not strict raw duplicate-key detection.

Wire names use `oms_json_member_name` on the element's namespace and source
name: OAM members use bare names; other qualified namespaces use Clark notation.
The unchanged `codec-choice` fixture executes both `{urn:choice}Alpha` and
`{urn:choice}Beta` within `{urn:choice}Pick`.

Supported: required-single concrete Choice alternatives of existing supported
Boolean, integral signed-64-bounded JSON domains, plain/checked Strings, enums,
concrete Records, and dependency-safe nested Choices. A Choice can be a required
or optional Record field or a directly selected message payload. Optional Record
wrappers are not optional alternatives.

Unsupported: optional/repeated/nillable alternatives, polymorphism/abstract
values, unsupported scalar/facet semantics, unqualified wire identity,
unresolved references, aliases/lists, unsupported inherited shapes, and cycles
rejected by existing model/emission planning. Readiness uses the same effective
alternatives as the model, checks named emitted dependencies and reachable
Record values, and reports the first failing alternative in source order.
Choice-free readiness counts and generated bytes remain unchanged.
